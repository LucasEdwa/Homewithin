# HomeWithin — Instagram Content Guide

### One Post Per Feature · 20-Second Mobile Videos

> **How to record:** Use your phone's native screen recorder (Control Center on iOS).  
> Open the app, start recording, follow the ON-SCREEN ACTIONS step by step, then stop.  
> Trim to ~20 seconds in Photos before posting.  
> Voice-over can be recorded during screen capture or added in CapCut/Reels editor.

## Recording Tips

| Tip                | Detail                                                                       |
| ------------------ | ---------------------------------------------------------------------------- |
| **Resolution**     | Record at 1080p or higher on your iPhone                                     |
| **Orientation**    | Portrait only (9:16 ratio for Reels/Stories)                                 |
| **Do Not Disturb** | Enable before recording to hide notifications                                |
| **Clean battery**  | Charge to 100%, hide clock if possible (Settings → Display)                  |
| **Demo account**   | Use a seeded test account, not your real profile                             |
| **Light theme**    | Record in light mode for best contrast in Reels                              |
| **Trim**           | Aim for exactly 18–22 seconds — Instagram Reels performs best at that length |
| **Captions**       | Add auto-captions in Instagram Reels editor before posting                   |
| **Cover frame**    | Pause on a clean, centered screen for your Reel cover                        |
| **Hashtag limit**  | Use 5–10 hashtags max for Reels (algorithm penalizes hashtag dumps)          |
